# Contribuindo com o HeatTurbo

Obrigado por ajudar. O objetivo não é ter o maior número de tweaks; é ter ajustes que possam ser explicados, medidos e desfeitos.

## Antes de enviar uma otimização

1. Explique qual gargalo ela resolve e em quais versões do Windows foi testada.
2. Use documentação oficial como fonte sempre que possível.
3. Implemente um teste de estado, uma ação de aplicação e uma restauração.
4. Não desative antivírus, atualizações, isolamento de núcleo ou paginação.
5. Não execute downloads ou scripts hospedados por terceiros.
6. Teste aplicação e restauração após reiniciar o Windows.
7. Informe se requer administrador ou reinicialização.

## Pull requests

Mantenha cada pull request pequeno, descreva como testar e inclua evidências antes/depois quando fizer afirmações de desempenho. Não inclua dados pessoais, chaves, executáveis ou resultados fabricados.
